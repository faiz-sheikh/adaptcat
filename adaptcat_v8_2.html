Data Lake Records
AdaptCAT v8.2 uses Supabase (PostgreSQL + PostgREST) for real-time data persistence. Every question response is logged to the responses table in real-time. The admin console at Ctrl+Shift+A provides export and IRT calibration monitoring.
Database
Supabase
PostgreSQL + RLS. Tables: profiles, item_bank, responses. Real-time logging of every IRT 3PL response event.
Auth
Custom JWT-free
SHA-256 password hashing in browser. 6-digit OTP verified against Supabase profiles.otp_code. AdaptCAT ID as primary session key.
Admin
Ctrl+Shift+A
Hardcoded secret gate. CSV/JSON export of full Data Lake. IRT calibration monitor (500-response threshold tracker per item).
Supabase Tables
TABLE
profiles
Stores user identity: adaptcat_id, full_name, email, branch, grad_year, password_hash, theta per product, OTP fields, verification status.
TABLE
item_bank
IRT item parameters: id, content JSONB, type, irt_difficulty (b), irt_discrimination (a), irt_guessing (c), hit_count, is_beta flag.
TABLE
responses (Data Lake)
Every interaction: user_id, item_id, accuracy, duration, theta, section_name, product_id, stage, language, timestamp. Primary source for IRT calibration and ERS model training.
⚠ Feedback Policy: Zero per-question answer confirmation during any active test. Full Analysis Reports generated after product submission. All responses logged to Supabase Data Lake in real-time. Admin console: Ctrl+Shift+A.
